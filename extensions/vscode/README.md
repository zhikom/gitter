# Gitter for VS Code

The elite Git client experience embedded directly inside Visual Studio Code.

## Features

- **Interactive Commit Graph:** GitKraken & Fork-level topological graph with branching curves, drag-and-drop cherry-picking, interactive rebase, and Ctrl+Click multi-commit comparison.
- **GitButler Virtual Branches:** Work on multiple features concurrently in the same working tree without stashing or switching branches.
- **Visual 3-Way Conflict Resolver:** Resolve merge conflicts visually block-by-block with live syntax-highlighted output preview.
- **Line-Level & Hunk Staging:** Sublime Merge-style staging of hunks and selected line ranges.
- **Commit History Timeline:** View full revision history for any file in your project.
- **Sublime Merge Search Syntax:** Search commits via `author:`, `hash:`, or `message:` filters.

## Usage

1. Open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`).
2. Type `Gitter: Open Interactive Commit Graph`.
3. Or click on the **Gitter** icon in the Activity Bar to access quick actions.
